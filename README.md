# scam-detector
# 🛡️ AI Scam & Phishing Detector

A real-time machine learning web application built with Python, scikit-learn, and Streamlit that analyzes text messages, emails, and URLs to detect potential phishing and scam patterns.

## 🚀 Live Demo
Check out the live application here: [Scam Detector Web App](https://scam-detector-wow.streamlit.app)

## 🛠️ Tech Stack
* **Language:** Python
* **Machine Learning:** scikit-learn (Logistic Regression, TF-IDF Vectorizer)
* **Data Manipulation:** Pandas
* **Web Framework:** Streamlit
* **Deployment:** Streamlit Community Cloud & GitHub

## 💡 Features
* Instant risk scoring for suspicious text messages and phishing attempts.
* Visual indicators (Warning/Success alerts) based on confidence probabilities.
* Fully containerized and deployed to the cloud for public access.
